	GET & POST

:- Get - Sends data in Url 

:- POST -Sends data in the reuest header (hidden)

:- php make name attribute as key for $_GET & $_POST
	eg:- <input type="text" name ="email"> 
		.here 'email' is  key
		. it can be used as $_GET['email'] or $_POST['email'] to read values or data

	theek hai.

	hone chahiye jahan request land kar rahi hai.
